# Luxury Collection - Exclusive Premium Products

A responsive product showcase store built with **HTML**, **CSS**, and **vanilla JavaScript**. Designed for luxury electronics with dynamic filtering by price range and category.

## Live Demo
🔗 [View Demo](https://mohammad-2012.github.io/Luxury-Product-Gallery/)

## Features

### 🎯 Filtering System
- **Filter by Category**: Ultra Premium (200M+), Premium (100M+), Affordable (Under 100M)
- **Price Range Slider**: Drag to filter products between 20M - 300M
- **Real-time Updates**: Products update instantly without page reload

### 📦 Product Display
- Dynamic product cards with image, description, price
- Category badges (PREMIUM / AFFORDABLE)
- Responsive grid layout for all devices

### 📊 Stats Counter
- Total products count
- Currently showing count after filtering

## Tech Stack
- HTML5
- CSS3 (Flexbox/Grid, responsive design)
- Vanilla JavaScript (No frameworks or libraries)

## How to Use
1. Clone the repository
2. Open `index.html` in your browser
3. Use filters or price slider to explore products
